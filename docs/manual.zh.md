# Scan Color Match 使用说明

本工具按数字参考图校正扫图的颜色。它只负责颜色：扫描仪 ICC 转换、裁切、旋转、去网等预处理请先完成。

- **支持格式：** 8 位 PNG、JPEG、TIFF、WebP，不支持 16 位图像；PNG/WebP 的透明区域会保留。
- **色彩空间：** 扫图和参考图应处于同一 RGB 色彩空间，通常是 sRGB。
- **项目：** 自动保存，导入和校色都不会改动原始文件。
- **界面语言：** 在「Language / 语言」菜单中切换中文或英文，重启后生效；首次运行跟随系统语言。

## 界面

- **左侧**：扫图列表；下方依次是拟合设置（拟合目标、迭代次数）、「运行校色」按钮（运行时变为「取消」）、进度条和状态、导出按钮。左上角显示项目文件夹名，鼠标悬停可看完整路径。
- **中间**：左边是扫图或校色结果，右边是当前选中的参考图（已对齐时按扫图坐标显示）。两边同步缩放和平移。下方显示对齐信息和色差读数。
- **右侧**：参考图列表、取样遮罩、LUT 模式、局部绘图工具、图层列表和「全部精修」。

### 扫图列表

| 标识     | 含义                                                                         |
| -------- | ---------------------------------------------------------------------------- |
| 绿色背景 | 结果就绪                                                                     |
| 橙色背景 | 需要重新运行校色，或需要「全部精修」                                         |
| 灰色背景 | 待处理                                                                       |
| 红色背景 | 出错或源文件丢失                                                             |
| 左侧色条 | 该扫图有参考图：蓝色为独立 + 联合训练，紫色为独立 LUT，青色为共享 + 联合训练 |
| 右侧括号 | 参考图数量                                                                   |

每行第一行是文件名，过长时省略中间部分（末尾的页码会保留）；第二行只在需要处理时显示具体的提示或错误。鼠标移到沿用其他扫图 LUT 的扫图上时，被沿用的那张会以虚线框标出。

### 项目

启动时自动打开位于程序数据目录的默认项目。用「文件 → 新建项目」可在一个空文件夹里建立新项目，用「打开项目」打开已有项目。项目文件夹保存项目文件、遮罩和运行缓存；「文件 → 清空项目」会清除扫图、参考图、图层和缓存，原图和已导出的文件不受影响。

## 添加扫图和参考图

1. 把扫图拖到左侧列表，或用「文件 → 添加扫图」。
2. 选中一张扫图，把它的参考图拖到右侧参考图列表，或用「文件 → 添加参考图」。每张扫图有自己的参考图列表，可以有多张，也可以没有。文件名不需要对应。
3. 对齐在运行校色时自动完成，参考图的尺寸、方向、裁切范围都不必与扫图一致。

**批量配对：** 「文件 → 批量导入（按顺序配对）」打开一个两列窗口，左列放扫图，右列放参考图，按行号一一配对；扫图多于参考图时，多出的扫图不配参考图。可以拖动行调整顺序。

**替换图片：** 把单张图片拖到左侧预览会替换当前扫图，拖到右侧预览会替换当前参考图；拖入多张则是添加。原图移动位置后，也可以这样重新关联。替换后需要重新运行校色。

**停用参考图：** 参考图前的复选框决定它是否参与校色。取消勾选后重新运行即可排除它，它的遮罩和相关图层都会保留。

**删除与恢复：** 选中后按 Delete 删除扫图或参考图；Ctrl+Shift+Z（或焦点在列表时 Ctrl+Z）恢复刚删除的项目。

### 一张扫图配多张参考图

每张参考图单独对齐、单独取样，样本会均衡后一起用于这张扫图的 LUT，避免像素多的那张主导结果。适合参考图各自对应扫图不同部分的情况，例如一张跨页插图拆成了两张图。两张参考图在重叠区域的颜色如果明显冲突，程序会放弃空间修正，只保留全局 LUT。

## 取样遮罩

取样遮罩决定参考图的哪些部分可以作为校色依据。它只限制训练用的样本，LUT 仍然作用于整张扫图。每张参考图各有一个遮罩，按参考图原图坐标保存，重新对齐后不受影响。

- **排除选区**（红色，默认）：涂上的部分不用。适合水印、网站文字、马赛克，以及扫图里没有的内容。
- **仅用选区**（绿色）：只用涂上的部分。适合参考图只有一小块与扫图对应的情况。

切换模式时已画的内容保留，只是含义反过来；什么都没画时两种模式都不做限制。

**例子：** 扫图内容是 A+B，参考图是 A+C，只有 A 是同一画面。可以在参考图上排除 C，也可以切到仅用选区并涂出 A。否则程序会试图把 B 的颜色拟合成 C 的颜色。

**编辑：** 点「编辑遮罩」，用多边形、画笔、橡皮擦在右侧参考图预览上绘制，每完成一个形状或一笔就自动保存。

- 多边形逐点点击，点击起点闭合；Backspace 删除最后一个点。
- 画笔和橡皮擦是硬边，选中它们时才显示「笔刷直径」。
- 快捷键：L / B / E 选择工具，X 在橡皮擦和上一个工具之间切换，Ctrl+Z / Ctrl+Y 撤销 / 重做，Esc 取消未完成的形状并退出编辑。
- 「显示遮罩」只控制是否显示，「清除遮罩」清空当前参考图的遮罩（可撤销）。

**精度：** 少量线稿、文字之类的细小差异，或颜色差异极大的小块内容，拟合时会被自动降低权重，不必画得非常精确；但成片的不对应内容需要排除。遮罩修改后需要重新运行校色。可用区域太小时会报「有效像素不足」，这时缩小排除范围或扩大仅用的区域。

## LUT 模式

LUT 模式是每张扫图单独的设置，在右侧「LUT 模式」下拉框中选择。

| 模式            | 适用             | 说明                                                                                                       |
| --------------- | ---------------- | ---------------------------------------------------------------------------------------------------------- |
| 独立 + 联合训练 | 有参考图（默认） | 用自己的参考图训练独立 LUT，同时把样本贡献给共享 LUT。大多数情况下效果最好。                               |
| 独立 LUT        | 有参考图         | 只用自己的参考图，不参与共享训练。适合灰度页，以及纸张、印刷与内页不同的封面封底，避免污染其他页面的 LUT。 |
| 共享 + 联合训练 | 有参考图         | 参与训练共享 LUT，自己也使用共享 LUT。适合参考图很少、只对应一小块，或独立 LUT 验证不通过的扫图。          |
| 共享            | 无参考图（默认） | 使用所有参与联合训练的扫图一起学出的共享 LUT。                                                             |
| 沿用 #N 的 LUT  | 无参考图         | 直接沿用第 N 张独立 LUT 扫图的 LUT，例如封底跟随封面；这种情况不需要共享 LUT。                             |

- 被沿用的扫图删除、改回共享或去掉全部参考图后，跟随它的扫图会自动改回共享。
- 共享 LUT 至少需要一张成功对齐、参与联合训练的扫图。
- 灰度页和彩页最好分批处理：两者的印刷方式不同，混在一起训练的共享 LUT 对两边都只能折中。
- 黑白网点漫画不适合本工具：网点图的灰度来自网点面积，逐像素的颜色映射改变不了网点本身。

## 运行校色

点「运行校色」会处理项目里的全部扫图，不只是当前选中的一张。扫图和参考图文件都没变时，重新运行会直接沿用上次的对齐结果。运行中按钮变为「取消」，取消后保留上一次完成的结果。

### 拟合目标

- **ΔE76**（默认）：直接最小化人眼色差，效果更好，每张扫图每轮多几秒。
- **RGB**：最小化 RGB 数值误差，最快，略不准。

无论选哪个，验证和界面上的色差都用 ΔE76；所选方式没通过验证时，程序会自动改用另一种再试一次。

### 迭代次数

迭代次数是独立 LUT 扫图最多做几轮全局校正（1–5，默认 2）。第 k 轮在第 k−1 轮的结果上重新拟合 LUT 和空间修正，修掉上一轮剩下的误差。

- 在作者的测试中，第 2 轮通常还能把色差再降 2–8%，第 3 轮只剩 1–2%。
- 轮数越多，越容易去贴合参考图里的错位、模糊和噪点，对样本里没出现过的颜色外推也更激进。
- 每一轮都要先在留出数据上验证。某一轮没通过时，这一轮仍会算出来，但只用作强度插值的终点，不再继续算下一轮。
- 使用共享 LUT 或沿用其他扫图 LUT 的扫图只有一轮。

修改拟合目标或迭代次数后需要重新运行校色。

## 图层与强度

右侧图层列表从上到下是局部图层，最底部是全局图层。上方的图层盖在下方的图层之上，拖动可调整顺序。

### 全局图层

代表整张扫图的 LUT 和空间修正。复选框关闭后，局部图层以原扫图为底图。可以重命名，不能删除或拖动。

右侧百分比是全局强度：0% 为原扫图，100% 为第一轮结果，200% 为第二轮结果，中间按比例插值。

- 运行后自动选择在校准样本上色差最低的强度。
- 点击百分比可输入，最高 500%；在上面滚动滚轮每次 ±10%；右键菜单可恢复自动。
- 调到超出已算轮数时，程序会用保存的对齐数据在后台补算后续轮次，不需要重新运行校色。如果某一轮没通过验证，强度最高只能到这一轮。
- 调整强度后先显示小尺寸预览，再在后台生成全分辨率结果。算过的强度会被缓存，切回去不需要重新计算。

### 局部图层

全局校正后，面积小、细节多的地方（脸、眼睛、小物件）颜色可能仍不够准，这时用局部图层精修。

1. 先运行一次校色，确认要修的区域在已对齐的参考图范围内。
2. 在右侧选中这个区域对应的参考图，点「新建图层」；也可以直接用画笔或多边形开始绘制，程序会自动建立图层。每个图层绑定创建时选中的那张参考图。
3. 用工具在左侧扫图预览上画出要修的区域：
   - **画笔 / 橡皮擦**（B / E）：「直径」是笔刷大小（图像像素），「硬度」是边缘软硬（0–100%，软边宽度随直径缩放）。
   - **多边形**（L）：逐点点击，点击起点闭合；只有一个「羽化」参数，表示轮廓内外各过渡多宽（图像像素，0 为硬边）。
   - Alt + 右键拖动：水平方向调直径或羽化，竖直方向调硬度。X 在橡皮擦和上一个工具之间切换，再次点击当前工具按钮或按 Esc 退出工具。
4. 点「全部精修」：按图层从下到上拟合有改动的图层，并自动选择各图层的强度。只画了遮罩不等于已经拟合颜色。

**画准遮罩：** 局部图层的颜色模型比较简单，对遮罩里没有采到样本的颜色外推能力较差。所以遮罩尽量只覆盖要修的区域；颜色差别很大的几个部位（例如皮肤和头发）最好分成多个图层，而不是放进同一个图层。

**实时预览：** 修改已拟合的图层时，结果会随笔刷实时更新；还没拟合的新图层在绘制时显示带羽化的遮罩。

**图层行的操作：**

| 位置                    | 作用                                |
| ----------------------- | ----------------------------------- |
| 复选框                  | 是否应用这个图层                    |
| 眼睛                    | 在预览上叠加显示遮罩                |
| 图像缩略图 / 遮罩缩略图 | 切换查看结果 / 黑白遮罩             |
| 百分比                  | 强度（0–200%），点击输入或滚轮 ±10% |
| ×                       | 删除图层（也可选中后按 Delete）     |
| 双击名字                | 重命名                              |

- 「保护暗线」会减弱很暗的线条上的颜色变化，避免线稿被染色。精修暗部图像时取消勾选该选框。
- 修改强度、可见性、保护暗线后直接重新合成，不需要重新拟合；修改遮罩后需要再点「全部精修」。

### 色差读数

预览下方显示 `ΔE76：遮罩 a → b | 全局 x → y | 最终 x → z`，数值是平均 Lab 色差，越小越好：

- **遮罩**：只在选中已拟合的局部图层时出现，表示这个图层在它的遮罩内开关前后的变化。
- **全局**：原扫图 → 全局校正结果。
- **最终**：原扫图 → 当前显示的结果（包括全局开关和所有局部图层）。

后两项在同一批对齐的校准像素上测量，便于比较。

## 导出

- 「导出当前」导出选中的扫图，「全部导出」导出所有就绪的扫图。导出目录对话框在默认项目下从第一张扫图所在文件夹打开，其他项目从项目文件夹打开。
- 输出 PNG，文件名为原扫图名加 `-color-matched`；重名时自动加序号，不覆盖已有文件。
- 在「文件」菜单可勾选「同时导出对比预览图」：生成原扫图 / 对齐后的参考图 / 修正后的结果三格对比图，多张参考图会按各自位置拼在同一格里，重叠处显示列表中靠前的那张。也可勾选同时导出 JSON 报告。
- 全部导出成功后会询问是否清空项目。

## 命令行

给懒人用的AI自动化接口。处理单张扫图和单张参考图，使用与界面相同的引擎：

```powershell

```

| 参数                           | 作用                                                 |

| `--format png\|webp`           | 输出格式，默认 PNG                                   |
| `--preview`                    | 同时输出对比图                                       |

## 常见问题

- **参考图对齐失败或对错位置**：参考图里有大量扫图中没有的内容时容易出现。先把参考图裁到与扫图对应的部分再添加。
- **独立 LUT 验证不通过**：检查参考图是否真的是同一画面、取样遮罩是否排除了不对应的内容；也可以改用共享 + 联合训练。
- **共享 LUT 验证不通过**：参与联合训练的页面颜色关系不一致，例如混入了灰度页或纸张不同的页面。把这些页面改为独立 LUT，或分批处理。
- **局部图层报「有效像素不足」**：遮罩太小，或不在参考图对齐范围内。扩大遮罩，或换一张覆盖该区域的参考图。
- **高 DPI 扫描、网点被分开了（例如 1200 DPI 下能看到青、品红、黄、黑各自的网点）**：先去网再校色。程序在缩小的工作图上学的是网点混合后的颜色，校正却逐像素作用在原图上；对单个纯色网点和网点间的纸白做非线性映射，混合后的颜色就会跑偏，局部图层也几乎取不到可靠样本。用扫描软件的去网功能，或适当模糊后缩小到 300–600 DPI，再放进本工具。
- **结果显示「需要重新运行」**：修改了图片、参考图、遮罩、LUT 模式或拟合设置后，旧结果会保留显示，直到重新运行校色。

## 算法说明

这一节说明程序具体做了什么、凭什么认为结果可信，以及它做不到什么。

### 校色的本质

校色就是找一个函数：输入扫图上某个像素的颜色，输出参考图上同一位置的颜色。程序先把参考图对齐到扫图上，在两张图的对应位置上成对取样（扫图颜色 → 参考图颜色），再用这些样本拟合这个函数。

所以结果的上限取决于两件事：

- **对应关系对不对：** 对齐是否准确，取到的样本是不是同一画面。
- **参考图本身是不是你想要的目标：** 程序会忠实地往参考图的颜色上靠。如果参考图本身画质很差，校色的结果也不会好。

### 1. 对齐

- 把扫图和参考图缩小到长边约 1800 像素，转成灰度并做局部对比度增强（CLAHE），让印刷和数字图的特征更容易对上。
- 用 SIFT 提取特征点，最近邻比值小于 0.74 才算匹配，再用 RANSAC（误差阈值 4 像素）估计参考图到扫图的单应变换。单应变换能处理缩放、旋转、平移和透视，但不能处理扫描时纸张的弯曲。
- 至少要有 40 个匹配、25 个一致点（内点），且内点比例不低于 25%，否则判为对齐失败，不会用错位的数据去拟合。
- 参考图和扫图文件都没变时，重新运行直接沿用上次的对齐结果。

### 2. 取样

- 拟合在「工作分辨率」上进行：长边约 1700 像素（不超过原图的 32%）。缩小本身就平均掉了网点、纸纹和扫描噪声。
- 只在可信的位置取样：参考图覆盖范围内、不透明、离对齐边界有一段距离，并且排除取样遮罩标出的部分。
- 只取平坦的颜色区域：按梯度强度排序，梯度最高的 32% 像素（线条、边缘、细节）不用。对齐哪怕差一两个像素，边缘处的颜色也会完全对不上，平坦区域则不受影响。
- 每张参考图随机抽取最多 3 万个样本。一张扫图有多张参考图、或多张扫图一起训练共享 LUT 时，各来源抽取相同数量，避免像素多的一方主导结果。

### 3. 全局 LUT

颜色映射是一个三次多项式：输出的每个通道都是输入 R、G、B 的 20 项多项式（常数、一次项、二次项、交叉项、三次项）的加权和，一共 60 个参数。这个形式足够表达扫描仪和印刷带来的曲线、偏色、通道串扰，又平滑到不会在样本之间产生突变。

- **ΔE76 目标：** 直接最小化校正结果与参考图之间的平均 Lab 色差（ΔE76），用高斯-牛顿法迭代求解，以 RGB 拟合的结果为起点。
- **RGB 目标：** 最小化 RGB 误差，并迭代 4 轮重新加权：误差特别大的样本（多半是错位、杂点或不对应的内容）权重按比例降低。
- **两种目标都带正则化：** 偏离「不改动」越多，代价越高。数据支持不足的方向（例如样本中很少出现的颜色组合）会自动保守，不会凭空乱改。
- **使用了取样遮罩时：** 遮罩往往意味着只有部分颜色有样本，所以 LUT 会被采样成 33³ 的网格，离已有样本颜色越远，修正越弱，最终回到原色。

### 4. 验证：为什么不会越修越差

每个 LUT 在被采用之前，都要在没有参与训练的数据上检验一次：

- **单张扫图：** 随机留出 20% 的样本，只用其余 80% 拟合，再在留出的样本上比较修正前后的平均色差。
- **使用了取样遮罩：** 按画面区域分成 5 份轮流留出，要求至少一半的区域变好。
- **共享 LUT：** 每次留出整页（最多 5 折），要求整体变好，且至少一半的页面变好。

检验不通过，这个 LUT 就不会被采用：程序会改用另一种拟合目标再试一次，仍不通过就报错，而不是静默输出一个更差的结果。迭代时每一轮都要重新通过检验。

这一步是判断结果靠不靠谱的关键：模型在训练数据上总能表现得不错，只有在没见过的数据上也变好，才说明它学到的是真实的颜色关系，而不是噪声。

### 5. 空间修正

LUT 对整页一视同仁，同一个颜色在页面任何位置都得到同样的修正。但扫描仪光照不均、书脊附近的阴影、印刷浓淡不均，都会让同一个颜色在不同位置有不同的偏差。空间修正专门处理这类与位置有关的偏差：

- 计算 LUT 之后每个位置与参考图的剩余 Lab 偏差，先限幅（亮度 ±7、色度 ±6）。
- 加权：线条、边缘处降低权重；偏差特别大的像素（多半是错位或不对应的内容）权重快速衰减。
- 大尺度高斯平滑：在原图上约 230 像素的范围内取平均，只保留缓慢变化的部分，细节和图案都不会被当成「偏差」。
- 结果再限幅（亮度 ±7.6、色度 ±9），并在参考图覆盖范围的边缘逐渐减弱到 0；参考图没覆盖的地方只用全局 LUT。
- 只有色差确实下降（至少 0.02）才采用；多张参考图在重叠区域的颜色明显冲突时（中位色差超过 6）也放弃。

### 6. 迭代与强度

第 k 轮把第 k−1 轮的结果当作新的扫图，重新拟合 LUT 和空间修正。第一轮已经修掉主要偏差，后面每一轮修的是上一轮剩下的部分，所以收益越来越小。每一轮都要重新通过验证；没通过的那一轮仍会算出来，但只作为强度插值的终点，不会再往下算。

全局强度在相邻两轮的结果之间按比例插值（200% 为第二轮，250% 为第二、三轮各一半）。自动强度在 0% 到最大值之间每隔 5% 计算一次色差，取最低的位置。

### 7. 局部图层

局部图层的模型比全局 LUT 简单得多：在遮罩内，用当前颜色的线性函数（4×3 个参数）预测还需要的 Lab 修正量。

- 样本只取遮罩内部（边缘收缩一圈）、参考图覆盖范围内、梯度不在最高 25% 的像素，最多 3 万个。
- 同样随机留出 20% 检验；不通过时退回到只做一个整体偏移，仍不通过就报错。
- 拟合时迭代降低大误差样本的权重，并带正则化。
- 修正幅度限幅：亮度最多 ±6、色度最多 ±12。
- 强度在 0–200% 中自动选择遮罩内色差最低的值。「保护暗线」会让亮度低于约 L\*=37 的像素逐渐减少修正，L\*=12 以下完全不修正。

模型简单是有意的：局部样本少、颜色范围窄，复杂模型很容易过拟合。代价就是外推能力弱，所以遮罩要画准，颜色差别大的部位要分图层。

### 8. 实测：在没见过的区域上也变好

以README中的实例扫图做检验：在每张图上按区域留出约 20% 的画面，LUT 和空间修正都不使用这些区域，只用它们打分（平均 ΔE76，越小越好）：

| 扫图                                   | 原图  | 第 1 轮 | 第 2 轮 | 第 2 轮在训练区域上 |
| -------------------------------------- | ----- | ------- | ------- | ------------------- |
| scan1（彩页）                          | 11.37 | 4.06    | 3.72    | 3.59                |
| scan2（彩页，两张参考图）              | 6.49  | 5.45    | 5.33    | 2.24                |
| scan3（彩页）                          | 8.22  | 2.85    | 2.65    | 2.40                |
| scan4（彩页，独立 LUT，配参考图 ref4） | 5.79  | 2.55    | 2.45    | 2.30                |
| scan4（彩页，无参考图，共享 LUT）      | 5.79  | 3.65    | —       | 未参与训练          |
| scan5（灰度页）                        | 2.25  | 0.95    | 0.87    | 0.79                |

- 在完全没参与训练的区域上，色差同样大幅下降，说明学到的是真实的颜色关系。
- 留出区域和训练区域的差距不大，没有明显的过拟合。
- scan4 测了两种做法。配上自己的参考图 ref4 用独立 LUT 时，色差降到 2.45；完全不用参考图、只靠 scan1–3 联合训练的共享 LUT 时（共享 LUT 只有一轮，整张图都没参与训练），也能降到 3.65，相当于拿到了有参考图时约 64% 的改善。共享 LUT 那一行的 ref4 只用于打分。
- scan2 留出区域的数值偏高：它在原图阶段就已经是 6.49（训练区域只有 3.56），很可能是留出的区域里包含了参考图与扫图内容不同的部分。这也说明了取样遮罩的重要性。

作为参考，通常认为：ΔE76 约为 1 时，两种颜色并排比较也很难分辨；2–3 时并排能看出差别；超过 5 就是明显的色偏。

### 9. 界面上的色差怎么看

界面上的「全局」「最终」色差，以及自动强度用的色差，都是在一批固定的平坦像素上测的，其中一部分参与过训练，所以会比真正的留出数值略乐观。它适合用来比较不同设置的相对好坏，而判断结果会不会越修越差，靠的是上面第 4 步的留出验证。每次运行的验证数值都记录在 `cache/runs/<运行 ID>/report.json` 里。

### 10. 做不到的事

- **超出印刷色域的颜色：** 参考图里有些颜色（比如很鲜艳的蓝、荧光色）印刷品本来就印不出来，扫图里也就没有。程序只能尽量靠近，无法凭空还原。
- **不是颜色的差异：** 网点、纸纹、模糊、锐度、摩尔纹、扫描噪声，都不是颜色映射能改变的。
- **参考图本身的问题：** 参考图被调过色、压缩严重或是不同版本时，程序会忠实地朝它靠拢。
- **同一个颜色需要不同修正、且不是缓慢变化的情况：** 例如某个小区域用了专色或特殊油墨。这类情况交给局部图层。
- **整页内容都对不上：** 参考图和扫图画面差异太大时，对齐或验证会失败，程序会报错，而不是给出一个看似正常的结果。

导出的 `.cube` LUT 在项目的 `cache/runs/<运行 ID>/lut` 文件夹里。
